# EduPlatform: исследование концепции

Промежуточная исследовательская фиксация. Source mode: online; completeness: partial.

Исходный запрос и ограничения сохранены в структурированном payload. Онлайн-источники прочитаны CLI-инструментом curl; даты и короткие выдержки находятся в research.yaml. Moodle Docs вернул HTTP 403 и не используется как доказательство.

Подтверждено: обязательны три роли, два прикладных сервиса, Kafka, PostgreSQL, Keycloak и Kubernetes. DeepSeek предлагает оценку, окончательное решение принимает преподаватель. Документация DeepSeek предупреждает о пустом JSON-ответе; Kafka требует отдельной координации записи во внешнюю БД.

Остаётся: сравнить идеи дополнительной ценности, выбрать концепцию, описать границы MVP, модель истории и небольшой эксперимент с критериями остановки. Открытые вопросы и рабочие допущения находятся в research.yaml.

Передача: разрешены только два исследовательских файла; отдельный HANDOFF.md и запрещённый .orchestra/questions.jsonl не изменялись. Продукт не реализовывался.
